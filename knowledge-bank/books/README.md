# Books

Open-licensed books kept with their example files. Notes and skills adapted from them are marked
"adapted from" with the same license.

| Book | Author / publisher | License | Used in |
|---|---|---|---|
| Essential Algorithms and Data Structures for Computational Design in Grasshopper, 2nd ed. (2024), PDF + 3 Grasshopper files | Rajaa Issa, Robert McNeel & Associates | CC BY-SA 3.0 US | `skills/gh-datatree` (matching rules, Simplify, tree operations) |
| The Essential Mathematics for Computational Design, 4th ed. (2019), PDF + Grasshopper file | Rajaa Issa, Robert McNeel & Associates | CC BY-SA 3.0 US | planned geometry and massing skills (vectors, transformations, NURBS) |

Paid books (for example Abhinav Bhardwaj's) are never stored here; see `docs/CHECKLIST.md`.
