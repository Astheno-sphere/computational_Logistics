# AEC Knowledge Graph — Ontology v0

## Node Types

| Type | What it represents | Key properties |
|---|---|---|
| **Theorist** | Named thinker whose ideas shaped AEC (theorists, architects, planners, engineers, computational pioneers) | `born`, `died`, `nationality` |
| **Movement** | Coherent intellectual current (New Urbanism, Parametricism, Garden City, etc.) | `year` (founding) |
| **Project** | Built or in-construction exemplar (Vauban, HafenCity, Sagrada Família, Bullitt Center) | `year`, `location` |
| **Standard** | Codified guideline (NACTO Urban Street, IBC 2021, LEED-ND v4.1, ASHRAE 90.1) | `year`, `scope` |
| **Metric** | Measurable quantity (FAR, Walk Score, U-value, RT60, EUI) | `unit`, `typical_min`, `typical_max` |
| **Pattern** | Reusable spatial/programmatic template (Alexander's 253 patterns + emerging) | `scope` |
| **Typology** | Formal type (perimeter block, T5 urban-center, woonerf, courtyard) | `scope` |
| **Tool** | Software / computational instrument (Rhino, Grasshopper, Karamba, Ladybug) | — |

All nodes share: `id` (slug, e.g. `theorist:jane-jacobs`), `name`, `aliases`, `summary`, `sources`, `tags`.

## Edge Types

| Type | Direction | Meaning |
|---|---|---|
| `INFLUENCED` | Theorist → Theorist | A's thinking shaped B's. Often cited as a teacher/critic relationship. |
| `AUTHORED` | Theorist → Pattern \| Movement \| Standard | The theorist created/founded this. |
| `BELONGS_TO` | Theorist \| Pattern → Movement | The entity is part of an intellectual movement. |
| `EXEMPLIFIES` | Project → Pattern \| Movement \| Typology | This project is a built demonstration of the abstract entity. |
| `CERTIFIED_BY` | Project → Standard | This project achieved the named certification. |
| `USES_TOOL` | Project \| Pattern \| Skill → Tool | The project/pattern/skill uses this tool. |
| `MEASURED_BY` | Project \| Pattern \| Typology → Metric | This entity has a typical value or range under the metric. |
| `SUPERSEDES` | Standard → Standard | Newer standard replaces older. |
| `REFERENCES` | Standard → Standard | One standard cites another normatively. |
| `MENTIONS` | Skill → any node | The skill body references the target (auto-generated by ETL from sibling plugins). |

Geographic location for projects is stored on the `location` property, not a separate edge.

## ID Conventions

`type:slug` — e.g. `theorist:jane-jacobs`, `pattern:30-activity-nodes`, `standard:leed-nd-v4-1`.

Slugs are kebab-case ASCII, derived from the canonical English name. Stable forever — never rename a slug, alias instead.

## Sources

Every node and edge can carry a `sources: list[str]` array. Strings are free-form (book title + year, URL, archive locator). The graph is a *knowledge graph* not a *belief graph* — citations matter.

## Versioning

The graph is rebuilt from JSONL on every `aec-kg build`. The DB itself (`.kuzu/`) is in `.gitignore`. JSONL is the single source of truth and lives in git.

To deprecate an entity, do NOT delete the row — set `tags: ["deprecated"]` and add a `SUPERSEDES` edge from its replacement.
